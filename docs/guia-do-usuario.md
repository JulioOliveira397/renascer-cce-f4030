# Guia do usuário (1 página)

Guia simples entregue ao usuário final. Linguagem sem termos técnicos, de propósito.

## Seu computador agora

- Liga em cerca de **30 segundos**.
- Seus arquivos antigos estão em **Documentos → "Arquivos do Windows"**.
- O sistema **se atualiza sozinho**. Quando aparecer o escudo na barra de tarefas, é só clicar e instalar.

## No dia a dia

| Quero… | Faço… |
|---|---|
| Abrir a internet | Ícone do **Firefox** na barra de tarefas |
| Usar o WhatsApp | Menu → **WhatsApp** (abre como aplicativo) |
| Encontrar meus arquivos | Menu → **Pasta pessoal** → Documentos |
| Desligar | Menu → botão de **desligar** |

## Regras de ouro

1. **Nunca compartilhe sua senha** com ninguém.
2. Se aparecer um pedido de senha de **administrador**, **não tente adivinhar**: fale comigo.
3. Não instale programas de sites desconhecidos. Use o **Gerenciador de Aplicativos** do menu.
4. Se algo estranho acontecer, **não desligue à força**: mande mensagem.

## Preciso de ajuda

- Deixe o notebook **ligado, aberto e com internet**.
- Mande mensagem para o suporte. Eu consigo ajudar à distância.

*(Os contatos reais do suporte estão na versão entregue ao usuário, não neste repositório público.)*
